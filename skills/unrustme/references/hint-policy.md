# Progressive help for Learn

Track hint level for the current conceptual obstacle. Start with the least revealing response that can move the learner forward; skip levels when their work shows they need a direct answer or they explicitly request one.

| Level | Help |
| --- | --- |
| H0 — Probe | One clarifying question or tiny counterexample that exposes the gap. |
| H1 — Nudge | Point to a relationship without naming the full technique. |
| H2 — Direction | Name a useful operation or data-structure family and why it may help. |
| H3 — Structure | Outline a short trace or pseudocode for the blocked step, not full code. |
| H4 — Explanation | Explain the full approach and implementation when requested or after sustained unproductive struggle; then invite independent reconstruction. |

Give one useful question at a time. If the learner stays stuck, change representation with a small table, trace, or analogy rather than repeating the same hint. Do not describe substantive H2/H3 guidance as “no hints.” Honor “just tell me,” time pressure, accessibility needs, and explicit requests for a full walkthrough. If the learner wants interview-style practice, offer hints only when requested or under their chosen interview rules.
